# Event Assets Directory

Place event-specific assets here. Each event gets its own folder matching the slug.

```
/public/events/
├── world-championship-2026/
│   ├── favicon.ico
│   ├── logo.png
│   ├── hero-bg.jpg
│   ├── og-image.jpg     (1200x630 recommended for social sharing)
│   └── sponsors/
│       ├── sponsor1.png
│       └── sponsor2.png
```

Referenced in `lib/event-config.ts` and the event landing page components.
