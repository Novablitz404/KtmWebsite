Subject
Feature Request: Adding a Telegram/Messenger-Style Group Chat with Multi-Room Support to the Tomatok App

Dear Tomatok Development Team,

On behalf of the World of Taekwondo Federation (WOTF) — the primary organization and official partner of Tomatok — we submit this formal feature request for the implementation of a Group Chat system with multi-room support within the Tomatok mobile application. As the designated official messaging platform of WOTF, Tomatok is the natural home for structured, community-level conversations across our federation, clubs, athletes, and officials.

At present, WOTF members continue to rely on third-party platforms — Facebook Messenger, Viber, and Telegram — for inter-club coordination, event announcements, and community discussions. This fragmentation weakens the Tomatok ecosystem and diminishes the value of having a dedicated official app. The addition of a Group Chat with Rooms feature would consolidate all WOTF communication within Tomatok, driving retention, daily active usage, and federation-wide adoption.

Core Concept — How It Works

The Group Chat system follows a two-tier hierarchy identical to how Telegram Supergroups and Facebook Messenger Groups operate — but organized with named "rooms" (channels) within a single group, much like how Discord organizes its servers. A user joins one WOTF group and can participate in multiple rooms inside it — each room serving a distinct purpose.

Core Feature Breakdown

Group Creation & Management

Any verified WOTF user can create a group, set a name, description, avatar, and join link. Admins manage membership, room creation, and posting permissions.

Multi-Room Chat Spaces

Each group contains unlimited named rooms (e.g., #announcements, #tournament-updates, #coaches-corner). Users navigate rooms via a sidebar — similar to Telegram topics or Discord channels.

Announcement-Only Rooms

Certain rooms (e.g., #announcements) can be set to read-only for regular members. Only admins or moderators can post, while others can react or reply — identical to Telegram Channels.

Push Notifications Per Room

Users can mute or enable notifications at the room level. WOTF can push important alerts (official announcements, event reminders) with priority delivery to all members.

Private & Public Groups

Groups can be set as public (searchable, open join) or private (invite-only, link-based access). Regional club groups can be private while national-level groups remain public.

Rich Media & Reactions

Messages support text, images, videos, documents, and polls. Emoji reactions are available on any message. Users can reply in-thread to keep room conversations organized.

How This Feature Strengthens the Tomatok Platform

Adding Group Chat with Rooms directly benefits Tomatok's growth metrics, retention, and position as the premier sports community messaging app in the Philippines.

📈 Daily Active Users Group Rooms create recurring reasons for WOTF members to open Tomatok daily — driving higher DAU and session frequency.
🏅 WOTF as Launch Partner WOTF's federation-wide adoption gives Tomatok a high-visibility launch case study for expanding to other sports organizations.
🔒 User Retention Bringing group communication natively into Tomatok prevents members from reverting to Messenger or Viber, locking in the user base.
🌐 Competitive Positioning A Group Rooms feature elevates Tomatok to the same tier as Telegram and Discord — cementing its place as a full-featured sports communication platform.

Summary: WOTF formally requests the Tomatok development team to implement a Group Chat with multi-room support within the Tomatok app. This feature will consolidate all WOTF community communication into a single, organized, role-aware platform — eliminating reliance on third-party apps, increasing Tomatok's daily active usage, and reinforcing WOTF's long-term commitment to Tomatok as its official and exclusive messaging platform.
